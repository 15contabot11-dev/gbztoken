Dicas para procurar o token

1. Abra baús

Procure baús durante as partidas. Cada baú elegível é uma nova tentativa.

2. Veja os eventos

Confira se há horários especiais anunciados dentro do próprio jogo.

3. Registre suas tentativas

Use o formulário para anotar quantos baús você já abriu.

Não existe método que garanta o token. Nunca informe sua senha, código de verificação ou dados de acesso da Epic Games.
